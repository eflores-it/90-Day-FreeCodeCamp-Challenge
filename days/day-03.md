# Day 3 — Debug a Pet Adoption Page

## Overview

For Day 3 of my 90-Day FreeCodeCamp Challenge, I completed the **Debug a Pet Adoption Page** challenge.

The goal of this challenge was to identify and fix errors in HTML code so that the page would display correctly and the links would work properly.

I practiced debugging HTML by comparing the broken code with the corrected version.

- Fixed an image element
